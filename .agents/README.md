# `.agents/` — suivi du travail des agents

Alimenté par la base [`ocourses/agents`](https://github.com/ocourses/agents).

- `runs/` : suivis des exécutions d'agents — `runs/<slug>-<run_id>.md`,
  plan + journal + bilan.
- `roles/<nom>.md` : (optionnel) surcharge d'un rôle pour ce dépôt.

Les fichiers de compilation ne doivent pas être ajoutés à ce répertoire.
